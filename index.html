The integer 9007199254740993 is stored as 9007199254740992 in a 64-bit float, and 16777217 is stored as 16777216 in a 32-bit one. 0.1 + 0.2 lands half an ulp from the true sum.

What it does

  • Exact stored value, bits and rounding error for binary64 and binary32
  • Next smaller and larger neighbors and the ulp spacing
  • Shortest text that round-trips
  • Arithmetic with the exact error in ulps
